# 竹林环拍三维重建与笛竹分选系统

从手机环拍竹林的视频出发，重建每根竹竿的位置、胸径、弯曲与竹节，估计竹龄，
并按笛子各调门的用料规格在俯视图上标注合用竹竿。纯 TypeScript 实现，零运行时第三方依赖，
视觉重计算放在 WebGPU（不可用时自动回退 CPU），圆柱拟合与竹龄估计在 Web Worker 中运行。

## 快速开始

```bash
npm install
npm run dev        # 开发服务器，打开浏览器按页面引导操作
npm test           # 单元测试（数学库、几何、选竹、评测，24 项）
npm run build      # 类型检查 + 生产构建
npx playwright test e2e   # 无头浏览器端到端测试（需先 npm run build 或 dev server）
```

## 四个页面（左侧导航）

1. **视频导入**
   - 合成模式：按 3 种密度（48/96/160 竿）× 3 种风力（无风/微风/大风）渲染环拍视频，
     同时生成每根竹竿与每帧相机的完整真值（JSON 可下载），红漆标尺竿直径 30 mm。
   - 真实模式：导入 mp4/webm/mov，等间隔抽帧。
2. **相机轨迹**：一键运行完整管线，展示相机俯视轨迹、特征/匹配统计、风动掩码占比、各阶段耗时与后端（WebGPU/CPU）。
3. **竹林重建**：对照硬性指标的精度面板、竹竿列表、单竿侧视（弯曲与竹节，叠加真值）。
4. **选竹标注**：可编辑的调门规格表、俯视图按调门配色标号、适配理由、清单 JSON 导出。

## 管线架构

```
视频帧
 └─ 特征层（vision/，CPU 回退；gpu/ 提供 WebGPU 内核）
     ├─ 灰度/Sobel/风动掩码（孤立闪烁点稀疏化，剔除风动竹叶、保留刚性竹竿）
     ├─ 竖棱检测（竖直能量 + 非极大值抑制 + 线段生长）
     ├─ 竹节环 / 斑痕 SIFT 风格描述子
     └─ 帧间匹配（Lowe 比率 + 同类约束 + 竖序一致性）
 └─ 相机定位（vision/tracking.ts、geometry.ts）
     ├─ 8 点 RANSAC 基础矩阵 → 本质矩阵 → 相对位姿（cheirality 选解）
     ├─ 环拍圆周先验：等角度布置在水平圆上，朝向圆心，规避单目尺度漂移
     ├─ DLT 三角化、DLT-PnP 精修、闭环旋转校正
 └─ 圆柱重建（recon/，Web Worker）
     ├─ 每条竖棱反投影为世界锚点，多视角空间聚类成竹竿
     ├─ 视线交会 + Gauss-Newton 拟合竖直圆柱（位置/直径/弯曲，带步长与边界约束）
     ├─ 竹节高度 1D 聚类、HSV 竹龄分类
     └─ 红漆标尺竿检测 → 米制尺度校正
 └─ 选竹（core/selection.ts）：直径/竹龄/节长/直度综合评分
 └─ 评测（core/evaluate.ts）：去质心 Procrustes 对齐后的 RMSE 与拆/并棒统计
```

## 关键约定

- 相机看向 **-Z**，世界坐标 y 轴向上；三角化、PnP、cheirality 全部统一在该约定下。
- 单目视觉无法恢复绝对尺度，系统输出任意单位的重建，再由已知直径的红漆标尺竿做米制校正。
- 环拍相机近似匀速圆周运动，这一先验用于稳定纯视觉轨迹（真实手持轨迹会有偏差）。

## 精度与已知限制

合成数据下端到端可稳定产出竹竿、竹龄分类与无拆/并棒结果，整条链路（渲染→特征→定位→
圆柱拟合→定标→选竹）在无头浏览器中自动跑通。达到题目要求的亚厘米/毫米级精度仍受以下因素制约：

- **单目尺度与相位**：无深度传感器时，等角度圆周先验的起始相位依赖本质矩阵旋转估计，
  累积误差会让重建整体与真值产生平移/旋转偏差；Procrustes 对齐可消除相似变换残差，但无法消除非刚性误差。
- **亚像素标尺**：低工作分辨率下 30 mm 标尺在画面中不足 1 像素，宽度测量受量化限制；
  建议真实作业时让标尺在近景占据足够像素，或提高抽帧分辨率。
- **密集遮挡**：茂密竹林中大量竹竿互相遮挡，单帧可见棱线不足，召回率下降。
- 要稳定达到位置 ≤10 cm、胸径 ≤1 mm 的硬性指标，建议接入深度信息（双目/RGB-D）或在
  环拍路径上布置多个已知坐标控制点，替代单一圆周先验。

## 目录

```
src/core/      类型、数学库、随机数、竹林生成、选竹规格、评测
src/render/    WebGL2 合成竹林渲染器与 GLSL 着色器
src/vision/    图像算法、特征、匹配、本质矩阵/PnP/三角化、相机跟踪、标尺检测
src/gpu/       WebGPU compute（灰度、Sobel、运动掩码、描述子匹配）与 CPU 回退
src/recon/     圆柱重建 Worker、锚点聚类、Gauss-Newton 拟合、竹节/竹龄
src/io/        视频采集与抽帧
src/ui/        四页面、状态管理、俯视图
test/          单元测试    e2e/   Playwright 端到端测试
```
